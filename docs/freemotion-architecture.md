# Free Motion Web Agent Architecture`n`n## Overview`n`nThe Free Motion Web Agent is a highly resilient, cost-effective, plug-and-play auto-application framework for `career-ops`. It abandons brittle DOM-scraping rules and API reverse-engineering in favor of an agent-orchestrated "Read, Think, Do" cascade. `n`nThe architecture relies on three tiers:`n1. **Tier 1 (Deterministic Parser):** A fast script to fill standard fields and extract the remaining DOM.`n2. **Tier 2 (Agent Orchestrator):** The `agy` CLI reads the remaining state, decides what to do, and issues targeted commands.`n3. **Tier 3 (Eye in the Sky):** A visual free-tier LLM validates screenshots prior to submission.`n`n## 3-Tier Cascade`n`n### Tier 1: Deterministic Parser (`lib/tier1-autofill.mjs`)`n- **Goal:** Fill 70-90% of obvious fields (Name, Email, standard demographics) deterministically.`n- **Cost:** $0, executes in milliseconds.`n- **Output:** Returns a token-efficient Accessibility Tree (A11y DOM) of *unfilled* or *unrecognized* interactive elements. Elements are tagged with ordinal references (e.g., `[e1]`, `[e2]`).`n`n### Tier 2: Agent Orchestrator (`agy` & `lib/tier2-execute.mjs`)`n- **Goal:** Handle edge cases, custom questions, and non-standard forms.`n- **Process:** The CLI agent (`agy`) is the orchestrator. It reads the Tier 1 output, acts as a text-based LLM reasoner, and issues commands to `lib/tier2-execute.mjs`.`n- **Examples:** `node lib/tier2-execute.mjs --action "TYPE" --target "e3" --value "5 years"` or `node lib/tier2-execute.mjs --action "CLICK" --target "e5"`.`n`n### Tier 3: Eye in the Sky Validator (`lib/tier3-validate.mjs`)`n- **Goal:** Prevent faulty submissions.`n- **Process:** Before `agy` executes a "SUBMIT" action, it runs the Tier 3 script. This takes a screenshot of the browser context and sends it to a free-tier multimodal API (e.g., Gemini 1.5 Flash).`n- **Output:** The script returns "VALID" if the form looks correct, or a description of visually apparent errors (e.g., red validation text).`n`n## Plug-and-Play Browser Engine`n`nTo bypass advanced anti-bot WAFs (Cloudflare Enterprise, DataDome, Turnstile), this system strictly abstracts browser instantiation inside `lib/browser-engine.mjs`.`n`n**DO NOT hardcode `chromium.launch()`.**`n`nInstead, the engine checks configuration:`n- **Local Mode:** Uses standard Playwright.`n- **CDP Mode (Stealth):** Uses `chromium.connectOverCDP()`.`n`nBy using CDP, the framework is ready to be paired with standalone C++ stealth daemons like [camofox-browser](https://github.com/jo-inc/camofox-browser). A user merely needs to start the Camoufox daemon and point the career-ops config (`BROWSER_MODE=cdp`, `CDP_ENDPOINT=ws://localhost:9222`) to the daemon. The exact same application logic continues to run untouched over the websocket.
